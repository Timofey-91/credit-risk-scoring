# Модель кредитного скоринга

## Описание проекта

В рамках проекта я разработал модель кредитного скоринга для прогнозирования вероятности дефолта клиента.

Цель — определить, какие факторы влияют на риск невыплаты и как можно использовать эти данные для принятия решений в андеррайтинге.

---

## Данные

В датасете представлены характеристики клиентов:

* кредитная нагрузка
* история просрочек
* доход
* возраст
* количество кредитных линий

Целевая переменная:

* `SeriousDlqin2yrs` — наличие дефолта (1 — да, 0 — нет)

---

## Анализ данных

В ходе анализа я выявил несколько закономерностей:

* у клиентов с дефолтом значительно больше просрочек
* такие клиенты в среднем моложе
* их доход ниже

Это говорит о том, что платёжная дисциплина и финансовая стабильность напрямую связаны с риском.

---

## Предобработка данных

Я выполнил следующие шаги:

* удалил неинформативный столбец
* обработал пропуски:

  * `MonthlyIncome` — заполнил медианой
  * `NumberOfDependents` — заполнил медианой
* удалил некорректные значения (`age = 0`)
* ограничил выбросы (winsorization):

  * по просрочкам
  * по `DebtRatio` и `MonthlyIncome`
  * исправил аномальные значения в `RevolvingUtilizationOfUnsecuredLines`

---

## Модель

Использовал логистическую регрессию.

Данные разделил:

* 80% — обучение
* 20% — тест

---

## Качество модели

ROC-AUC: ~0.84

Модель показывает хорошую способность разделять клиентов по уровню риска.

---

## Ключевые факторы риска

По результатам модели:

Увеличивают риск:

* высокая кредитная нагрузка
* наличие просрочек (особенно 90+ дней)

Снижают риск:

* более высокий доход
* более старший возраст

Полученные результаты логичны и соответствуют реальному поведению клиентов.
